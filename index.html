Planeación y control con datos que se pueden verificarPlanning and control with data that can be checked

Este portafolio reúne los sistemas que construyo para el trabajo de planeación y control en una planta: del reporte de falla a la solicitud de entrega, del P&ID al subsistema, del cronograma a la certificación. Cada proyecto parte de un problema de planta, se compara con el método que reemplaza y declara lo que no hace.This portfolio brings together the systems I build for planning and control work in a plant: from the fault report to the handover request, from the P&ID to the subsystem, from the schedule to certification. Each project starts from a plant problem, is compared with the method it replaces and states what it does not do.

04 · Metodología04 · Methodology

Las reglas que siguen los ocho proyectosThe rules all eight projects follow

Fijadas antes de escribir código e iguales para todos. Un proyecto no se publica si no las cumple.Set before writing any code and the same for all. A project is not published unless it meets them.

Criterio de terminadoDefinition of done · estado del P1· P1 status

  • La evaluación corre con make eval y reproduce las cifras del README.The evaluation runs with make eval and reproduces the README figures.
  • La demo funciona sin credenciales ni datos privados.The demo runs without credentials or private data.
  • El README declara qué no hace el sistema.The README states what the system does not do.
  • Se levanta con un comando: make setup y make demo sí; Docker escrito y sin probar.Starts with one command: make setup and make demo yes; Docker written and untested.

Lo que separa una demo de un sistema confiable.What separates a demo from a reliable system.

Una demo se juzga por su mejor caso; un sistema de planta, por lo que hace el día que llega un tag mal escrito o falta una hoja de datos. Por eso cada proyecto mide contra el método que reemplaza, dice dónde pierde y no emite nada irreversible sin una persona.A demo is judged by its best case; a plant system, by what it does the day a misspelled tag arrives or a datasheet is missing. That is why each project measures against the method it replaces, says where it loses and issues nothing irreversible without a person.

Planta de referencia comúnCommon reference plant

Una estación de compresión con cuatro unidades y tags ISA 5.1 con formato AREA-TIPO-NN. Todos los proyectos leen y escriben sobre los mismos tags.A compression station with four units and ISA 5.1 tags in AREA-TYPE-NN format. All projects read and write the same tags.

Origen de cada datoOrigin of every data point

Cada tabla y cada figura declara si el dato es público, sintético o derivado. Los públicos se descargan con un script; los sintéticos llevan semilla fija y se calibran con una cifra publicada.Every table and figure states whether the data is public, synthetic or derived. Public data is downloaded by a script; synthetic data has a fixed seed and is calibrated against a published figure.

Línea base obligatoriaMandatory baseline

Cada modelo se compara con el método clásico que reemplaza, en la misma tabla. Sin línea base el proyecto no se publica.Every model is compared with the classical method it replaces, in the same table. Without a baseline the project is not published.

Partición por entidadSplit by entity

Entrenamiento, validación y prueba se separan por soldador, por plano o por equipo, nunca al azar sobre filas.Training, validation and test are split by welder, by drawing or by equipment, never at random over rows.

Agentes acotadosBounded agents

Todo agente usa herramientas deterministas (consulta al grafo, solver, simulación), nunca calcula por su cuenta y cita la fuente de cada salida.Every agent uses deterministic tools (graph query, solver, simulation), never computes on its own and cites the source of every output.

Aprobación humanaHuman approval

Permisos, aislamientos, aceptación de soldaduras y liberación de subsistemas exigen aprobación humana registrada.Permits, isolations, weld acceptance and subsystem release require recorded human approval.
